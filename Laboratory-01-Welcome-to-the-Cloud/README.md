# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic concepts of cloud computing and Linux command-line operations. It provides hands-on experience in navigating directories, creating files and folders, and organizing files using the terminal.

## Objectives

* Understand the basic use of the Linux terminal.
* Learn how to navigate and manage directories.
* Create and organize files using Linux commands.
* Practice using basic Linux commands.
* Prepare a structured repository for laboratory activities.

## Activities Performed

* Created the required directory structure for the laboratory.
* Created Markdown files for the laboratory documentation.
* Created and organized folders for screenshots.
* Used the Linux terminal to navigate directories and manage files.
* Checked the contents of directories using Linux commands.
* Organized the laboratory files according to the required repository structure.

## Linux Commands Used

* `pwd` – Displays the current working directory.
* `ls` – Lists files and folders in a directory.
* `cd` – Changes the current directory.
* `mkdir` – Creates a new directory.
* `ls -R` – Displays files and folders recursively.
* `cat` – Displays the contents of a file.
* `nano` – Opens a text file for editing.

## Skills Learned

Through this laboratory activity, I learned how to use basic Linux commands, navigate the file system, create and organize files and directories, and manage files through the terminal. I also learned how to structure and document laboratory activities in a GitHub repository.
