## Guide Questions

### 1. Which cloud provider offers the broadest range of services?
**Answer:** AWS offers the broadest range of services, with over 200 fully featured offerings covering compute, storage, databases, AI/ML, IoT, and more. Its maturity and first-mover advantage have made it the most comprehensive cloud platform available today.

### 2. Which provider best integrates with Microsoft technologies?
**Answer:** Microsoft Azure best integrates with Microsoft technologies because it is built by Microsoft itself. It natively supports Windows Server, Active Directory, Microsoft 365, and other Microsoft enterprise tools, making migration and hybrid setups seamless for organizations already using these products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
**Answer:** Google Cloud Platform (GCP) is strongest in AI/ML and Kubernetes. Google created Kubernetes, and GKE is the most mature managed Kubernetes service, while Vertex AI and TPUs give GCP a clear edge in AI and machine learning workloads.

### 4. Which cloud platform would you personally choose and why?
**Answer:** I would personally choose AWS because of its vast service offerings, global infrastructure, and strong community support. Its free tier and extensive documentation also make it ideal for learning and experimentation, which is helpful for students and aspiring cloud engineers.
