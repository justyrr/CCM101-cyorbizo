# Reflection: The Cloud Security Engineer

In this laboratory, I learned how to improve server security by configuring a firewall using UFW in Ubuntu. I practiced allowing specific ports, setting default firewall rules, and checking the firewall status. These tasks helped me understand how a firewall controls network traffic and protects a server from unwanted connections.

One important lesson I learned is that not all connections should be allowed. The Principle of Least Privilege and the Default Deny policy help limit access to only what is necessary. I also realized that leaving unused ports open can create security risks, especially when dealing with sensitive services such as databases.

This activity helped me understand that securing a server requires careful configuration and regular monitoring. Even a simple mistake in firewall settings can affect the security or accessibility of a system. As an IT student, I can apply these practices to future projects involving Linux, networking, and cloud infrastructure.

Overall, this laboratory improved my understanding of basic server security. It also gave me more experience using Linux commands and showed me how proper firewall configuration can help protect systems and data from unauthorized access.
