# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world's most comprehensive and broadly adopted cloud platform, launched in 2006 by Amazon. It offers over 200 fully featured services from data centers globally, serving millions of customers from startups to Fortune 500 companies.

## Global Infrastructure
AWS has a global infrastructure spanning:
- **Regions:** 30+ geographic regions worldwide
- **Availability Zones:** 90+ AZs across regions
- **Edge Locations:** 400+ points of presence for content delivery
- Major regions include North America, South America, Europe, Asia Pacific, Middle East, and Africa.

## Cloud Management Console
The **AWS Management Console** is a web-based application that provides centralized access to all individual AWS service consoles [citation:2]. It allows users to:
- Search for services using Unified Search
- Access AWS CloudShell directly from the console
- View account and billing information
- Customize the AWS Console Home with widgets
- Access all AWS event notifications
- Chat with Amazon Q for AI-powered assistance
- **URL:** https://console.aws.amazon.com [citation:10]

## Four Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – Virtual servers in the cloud
2. **Amazon S3 (Simple Storage Service)** – Scalable object storage
3. **Amazon RDS (Relational Database Service)** – Managed databases
4. **AWS Lambda** – Serverless compute service

## Three Advantages
1. **Broadest range of services** – Over 200 services for almost any use case
2. **Global reach** – Largest global infrastructure footprint
3. **Mature ecosystem** – Extensive documentation, community, and certifications

## Typical Enterprise Use Cases
- Hosting web and mobile applications
- Big data analytics and data warehousing
- Machine learning and AI workloads
- Disaster recovery and backup solutions
- Enterprise migration and hybrid cloud
