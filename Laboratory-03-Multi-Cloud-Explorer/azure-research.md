# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform launched in 2010 by Microsoft. It provides a growing collection of integrated services—compute, storage, data, networking, and app—that help organizations move faster, do more, and save money [citation:7]. Azure is known for its strong integration with Microsoft's existing enterprise products.

## Global Infrastructure
Azure has a global infrastructure spanning:
- **Regions:** 60+ regions worldwide (more than any other cloud provider)
- **Availability Zones:** Available in most regions
- **Edge Locations:** 190+ network points of presence
- Major regions include North America, Europe, Asia Pacific, Middle East, and Africa.

## Cloud Management Console
The **Azure Portal** is a web-based unified console that allows users to:
- Build, manage, and monitor everything from simple web apps to complex cloud applications
- Create custom dashboards
- Access Azure Cloud Shell
- Manage billing and subscriptions
- **URL:** https://portal.azure.com

The official Azure website can be found at: https://azure.microsoft.com [citation:3]

## Four Core Services
1. **Azure Virtual Machines** – Scalable computing resources [citation:13]
2. **Azure Blob Storage** – Object storage for unstructured data [citation:13]
3. **Azure SQL Database** – Managed relational database [citation:13]
4. **Azure Functions** – Serverless compute service

## Three Advantages
1. **Seamless Microsoft integration** – Works natively with Windows Server, Active Directory, Microsoft 365
2. **Enterprise-grade security** – Strong compliance and security certifications
3. **Hybrid cloud capabilities** – Best for hybrid environments with Azure Arc

## Typical Enterprise Use Cases
- Migrating on-premises Windows Server workloads
- Enterprise applications and ERP systems
- Hybrid cloud deployments
- Identity and access management
- DevOps and CI/CD pipelines
